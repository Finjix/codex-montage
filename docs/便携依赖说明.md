# 便携依赖

本套件在 64 位 Windows 上从 `dependencies/python/python.exe` 启动。解释器为 Python 3.13.15 Windows embeddable package，模块位于相邻的 `Lib/site-packages`；`python313._pth` 将模块路径固定在包内。启动与部署脚本不读取系统 Python，也不运行 pip 或 winget。

解释器来源：[Python 3.13.15 官方便携包](https://www.python.org/ftp/python/3.13.15/python-3.13.15-embed-amd64.zip)。Visual C++ DLL 来自 [Microsoft 官方 x64 Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe)，以应用本地方式放在解释器目录；随包提供其 14.44.35211.0 版本。Python 扩展模块使用与 3.13 兼容的 Windows wheel，版本信息保存在各自的 `.dist-info` 中。

主要运行模块包括 faster-whisper 1.2.1、CTranslate2 4.8.2、PyAV 17.1.0、NumPy 2.2.6、Pillow 12.3.0、OpenCV 5.0.0.93 和 ONNX Runtime 1.23.2。项目旧版的 `cp310` 模块已移除。原有 `rapidocr-onnxruntime` 不支持 Python 3.13，且当前项目代码没有调用它，因此没有放入便携运行时。

所有依赖集中在根目录 `dependencies/`：`python/` 存放解释器和模块，`ffmpeg/` 存放 FFmpeg 与 FFprobe，`models/` 存放完整 Whisper 模型及其缓存索引。根目录的 `runtime-lock.json` 和 `.manifests/dependencies.json` 对依赖进行哈希校验；修改任何运行文件后，应先重建语义包清单，再运行 `dependencies\python\python.exe tools\build_ff_suite.py build`。
