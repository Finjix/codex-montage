# V20.2.5 FF版跨电脑部署

1. 完整解压ZIP，不要在压缩包内运行。
2. 双击 `start.cmd`。
3. 包内自带FFmpeg、FFprobe、Python模块、完整faster-whisper模型、`portable_frame_renderer.py`、`frame_range_repair.py` 和 `winky_ledger.py`；不会借用旧项目脚本。
4. 目标电脑需要64位Windows、Codex桌面端和Python 3.10 x64。`start.cmd` 会优先通过 winget 安装；没有 winget 时，从 [Python 3.10.11 Windows x64](https://www.python.org/downloads/release/python-31011/) 安装后重新运行。
5. 默认安装到 `%USERPROFILE%\CodexMontageFF\20.2.5`。不要改到超过90字符的深层目录，否则 Windows 可能因 PyAV DLL 路径过长而加载失败。
6. 三个 Codex 技能源码已经在包内。部署器安装到 `%CODEX_HOME%\skills`，并在官方用户技能目录 `%USERPROFILE%\.agents\skills` 建立无重复体积的目录连接；不需要从第三方插件市场获取。
7. 部署器执行V20.2.5回归测试、完整哈希校验、运行时闭包校验和FF控制器preflight，失败不会注册技能。
8. 完成后彻底退出并重新打开Codex。新对话应能看到 `montage-three-part-orchestrator-ff`、`semantic-analysis-training-backup-v20` 和 `ffmpeg-montage-controller`。

发送前可运行 `start.cmd -PreflightOnly`，只验证包体、Python、FFmpeg、FFprobe 和模型，不复制或安装任何内容。

本版本不需要剪映。最终画面裁切只认源帧号；缺少帧字段或只有秒数的计划会被拒绝。最终释放必须经过V20.2语义门禁、帧计划门禁、FFmpeg控制器和60fps后编码密集终检。
