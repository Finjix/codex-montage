# V20.2.5 FF版跨电脑部署

1. 完整解压ZIP，不要在压缩包内运行。
2. 双击 `start.cmd`。
3. 包内自带 Python 3.13.15、对应模块、Visual C++ DLL、FFmpeg、FFprobe、完整 faster-whisper 模型以及剪辑脚本；不会查找或安装系统 Python。
4. 目标电脑需要64位 Windows 和 Codex 桌面端。部署全程使用 `dependencies/python/python.exe`，无需 winget 或联网下载依赖。
5. 默认安装到 `%USERPROFILE%\CodexMontageFF\20.2.5`。不要改到超过90字符的深层目录，否则 Windows 可能因 PyAV DLL 路径过长而加载失败。
6. 三个 Codex 技能源码已经在包内。部署器在 `%CODEX_HOME%\skills` 和 `%USERPROFILE%\.agents\skills` 建立指向已部署组件的目录连接，不再复制技能包；不需要从第三方插件市场获取。
7. 部署器执行V20.2.5回归测试、完整哈希校验、运行时闭包校验和FF控制器preflight，失败不会注册技能。
8. 完成后彻底退出并重新打开Codex。新对话应能看到 `montage-three-part-orchestrator-ff`、`semantic-analysis-training-backup-v20` 和 `ffmpeg-montage-controller`。

发送前可运行 `start.cmd -PreflightOnly`，只验证包体、便携 Python 与模块、FFmpeg、FFprobe 和模型，不复制或安装任何内容。部署后在 Codex 中使用三件套技能；如需手动预检，可从套件根目录运行 `dependencies\python\python.exe components\montage-three-part-orchestrator-ff\scripts\three_suite_ff.py preflight`。

本版本不需要剪映。最终画面裁切只认源帧号；缺少帧字段或只有秒数的计划会被拒绝。最终释放必须经过V20.2语义门禁、帧计划门禁、FFmpeg控制器和60fps后编码密集终检。
