# V20 FF three-part orchestrator

V20.2.5 accepts semantic completion only when the authorized-output count matches the complete declared batch and the release hash-binds a passing exhaustive prelock audit created with the packaged current invalid-range registry. Controller delivery must contain exactly the same plan IDs. Controller validation additionally requires the final encoded opening-family release gate.

Repairs use the same complete state machine. A user-rejected candidate invalidates the whole dependency closure; every dependent output must be re-authorized, re-rendered and re-reviewed. Task-local plan mutation, ad-hoc renderer scripts, partial post-QC or direct replacement of delivery files cannot produce a release receipt. Clean or intermediate media must retain original-source frame lineage, and final QC must use `ffmpeg-post-encode-qc/v20.5` with fresh output ASR and expected first-token alignment.

V20.2 is frame-native. Resolve the bundled `frame_plan_gate`, `portable_renderer`, `frame_range_repair`, and `winky_ledger` interfaces from `suite_registry.json`. A seconds-only plan, an external task-local renderer path, an unresolved placeholder, or a premaster without `render_mode: source_frame_ranges/v1` is a hard failure.

Order is mandatory: `immutable semantic evidence -> separate independent candidate review -> FFmpeg controller -> exact-cut machine signal gate -> independent post-encode review -> completion`.

Resolve components from `suite_registry.json`. Never substitute old candidate approvals, skip V20 invalid-range checks, accept generator-written passes, or release on technical validation alone.

Run `dependencies/python/python.exe components/montage-three-part-orchestrator-ff/scripts/three_suite_ff.py preflight` from the suite root, then invoke the same script with `init` and its required arguments. Use this bundled Python 3.13.15 for the executor and every child process. Completion requires the V20 semantic receipt, FF preflight, exact-60 delivery manifest, passing independent post-encode QC and passing FF controller validation.
